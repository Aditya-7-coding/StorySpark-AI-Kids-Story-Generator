# StorySpark AI – Story Generator for Kids

## Project Description
StorySpark AI is an AI-powered application that generates personalized and creative stories for children using Google Gemini AI. It creates age-appropriate stories based on the child's name, age, selected genre, characters, moral values, and preferred language.

## Features
- Personalized stories using child's name and age
- Multiple story genres
- Custom characters and moral values
- Story generation using Google Gemini AI
- Supports English, Hindi, and Marathi
- Regenerate stories
- Child-friendly and easy-to-use interface

## Technologies Used
- React
- TypeScript
- Vite
- Node.js
- Express.js
- Google Gemini AI API
- HTML and CSS

## Installation

1. Clone the repository:
   `git clone https://github.com/Aditya-7-coding/StorySpark-AI-Kids-Story-Generator.git`

2. Open the project folder:
   `cd StorySpark-AI-Kids-Story-Generator`

3. Install dependencies:
   `npm install`

4. Create a `.env` file in the root folder and add your Gemini API key:
   `GEMINI_API_KEY=YOUR_GEMINI_API_KEY`

5. Start the application:
   `npm run dev`

6. Open the local URL displayed in the terminal.

## Project Objective
The objective of StorySpark AI is to encourage children's creativity, imagination, and reading habits through personalized AI-generated stories.
